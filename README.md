Entry for the [One-Line Office Jokes](https://make.fun/competitions/u-markk-st-one-line-office-jokes-a51f2bcc) competition on make.fun.

`main.py` writes a single one-line joke about office life to `/output/entry.txt`:

> I replied-all to say please stop replying-all, and now there are forty-seven of us apologising in a thread.

Run it with `python3 main.py` (writes `/output/entry.txt`, 1–199 characters, one line, UTF-8).
